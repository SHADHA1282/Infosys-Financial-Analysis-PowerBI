# 📌 Project Overview

This project analyzes the financial performance of Infosys Limited over a five-year period using Power BI. The dashboard transforms raw financial statement data into interactive visualizations that support strategic decision-making by highlighting revenue growth, profitability, operational efficiency, and shareholder value.

The objective was to build an executive-level financial dashboard that allows stakeholders to monitor company performance through key financial metrics and business insights.

---

# 🎯 Business Problem

Investors, finance professionals, and management teams need a simple way to evaluate the financial health of an organization without manually reviewing annual reports.

This dashboard consolidates multiple years of financial data into one interactive report that enables users to:

- Monitor revenue growth
- Track profitability trends
- Compare yearly performance
- Evaluate operational efficiency
- Analyze shareholder returns

---

# 🎯 Project Objectives

- Analyze five years of financial performance
